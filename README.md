Entry for the [One Line, One Laugh](https://make.fun/bounty/u-4z4ghtbwm1fn7mibrqum4bxgfghhgqzriyhd8v3-one-line-0be61e5a) bounty on make.fun.

`main.py` (Python 3, stdlib only, no network) writes a single original
one-liner — one funny line, whole and self-contained — to
`/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable
is set).

Run it locally:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/one-line-out python3 main.py
cat /tmp/one-line-out/entry.txt
```
